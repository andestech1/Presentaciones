# Codex & n8n: Cómo dejar de pelearte con tus flujos

**Speaker:** Nacho Rigoni

---

## De qué trata

Una charla práctica sobre cómo utilizar Codex para desarrollar, mantener y escalar automatizaciones en n8n. A partir de problemas reales con flujos complejos, se muestra una forma de organizar el desarrollo utilizando MCP, IA y una arquitectura más mantenible para construir workflows.

---

## Temario

### El problema

- Cómo comenzaron los proyectos en n8n
- Automatizaciones simples que fueron creciendo
- El aumento de la complejidad con el tiempo

### Cuando todo empieza a romperse

- Flujos cada vez más complejos
- Subflujos y reutilización
- Múltiples clientes y proyectos
- Un único servidor para todo
- Errores difíciles de encontrar
- Flujos complicados de testear y mantener

### Replanteando la arquitectura

- Organizar el desarrollo
- Separar responsabilidades
- Pensar los flujos como software

### Introducción a MCP

- Qué es MCP
- Cómo ayuda a trabajar con automatizaciones
- Integración con el flujo de desarrollo

### Codex + n8n

- Pedirle a Codex que genere workflows
- Traducir requerimientos a flujos de n8n
- Limitaciones y desafíos actuales
- Iterar sobre las respuestas del modelo

### Arquitectura propuesta

- Codex como asistente de desarrollo
- MCP como intermediario
- Comunicación con n8n
- Uso de herramientas (Tools)
- Integración con APIs y servicios externos

### Demo

- Construcción de workflows utilizando Codex
- Ejemplos prácticos
- Experimentación con el flujo completo

---

## Conceptos principales

- Automatización con n8n
- Desarrollo asistido por IA
- MCP (Model Context Protocol)
- Organización de proyectos complejos
- Arquitecturas para workflows mantenibles
- Uso de herramientas desde modelos de lenguaje

---

## Requisitos

- Conocimientos básicos de n8n
- Interés en automatización
- Familiaridad con herramientas de IA
- Ganas de experimentar con nuevas formas de desarrollar workflows

---

## Recursos

- n8n
- Codex
- Model Context Protocol (MCP)
